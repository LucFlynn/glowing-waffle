# AI Landing Page Factory Starter

This starter contains two plain HTML/CSS pages:

- `index.html` — a directory-style homepage that routes visitors to the right offer.
- `offer.html` — a focused main-offer or lead-magnet page with one primary conversion action.
- `styles.css` — shared styling for both pages.
- `CUSTOMIZE.md` — a short brief and reusable AI prompt for adapting the pages.

## Use it

1. Open the folder in VS Code.
2. Open `index.html` and `offer.html`.
3. Replace every phrase inside square brackets.
4. Preview the pages locally.
5. Commit the folder to GitHub and connect the repository to your preferred hosting platform.
6. Replace the placeholder form action when you are ready to connect the form.

The starter deliberately contains no analytics tags, click-ID capture, CRM routing, or hidden tracking fields. Those belong to the conversion-signal implementation that follows the page build.

## Page logic

The templates are original, but their structure is informed by MECLABS research:

- Make the visitor’s location and next step immediately clear.
- Express one credible value proposition.
- Arrange evidence and supporting information around the decision.
- Reduce friction and anxiety at the point of action.
- Give a directory visitor distinct, self-identifying routes instead of three vague, equally weighted choices.

The offer page also reflects the useful lead-magnet principle that the free resource should produce a complete, valuable result rather than merely tease the paid offer.
